## 8. 사람이 눈으로 확인해야 할 것

기계가 판정할 수 없는 것들입니다. 루프가 `SUCCESS`여도 이건 남습니다.

- 글이 자연스럽게 읽히는가
- **사진이 그 관광지가 맞는가** (기계는 열리는지만 기록으로 확인합니다)
- 정보가 사실인가 (특히 환율·항공권 가격처럼 자주 바뀌는 것)
- 취향 설명이 내 말과 정말 맞는가
